# FPGA

FPGA projects in VHDL. Each project has its own folder with its own README.

- **[FPGA_CPU_Verification](FPGA_CPU_Verification)**: an 8-bit CPU in two versions (hardwired and
  microprogrammed control unit) with a self-checking UVVM testbench that runs in GHDL on GitHub Actions.
  ![FPGA_CPU_Verification tests](https://github.com/conductive-brain/FPGA/actions/workflows/FPGA_CPU_Verification.yml/badge.svg)
